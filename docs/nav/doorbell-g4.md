# Doorbell G4

Models: `lumi.camera.agl002`, `lumi.camera.acn005`

The integration exposes G4 controls and sensors through Aqara Open API v3. The experimental camera prerelease can also create a Home Assistant `camera` entity by pairing the G4 with a separate go2rtc instance.

See [Camera streaming setup]({{ '/devices/#cameras' | relative_url }}) for the prerelease disclaimer and configuration steps.
