# Doorbell G410

Models: `lumi.camera.acn017`, `lumi.camera.agl006`

The integration exposes G410 controls and sensors through Aqara Open API v3. Version `v1.4.0` and later can also create a Home Assistant `camera` entity by pairing the G410 with a separate go2rtc instance.

See [Camera streaming setup]({{ '/camera-streaming/' | relative_url }}) for configuration steps and current limitations.
