# Camera Hub G3

Models: `lumi.camera.gwpgl1`, `lumi.camera.gwpagl01`

The integration exposes G3 controls and sensors through Aqara Open API v3. The experimental camera prerelease can also create a Home Assistant `camera` entity by pairing the G3 with a separate go2rtc instance.

See [Camera streaming setup]({{ '/camera-streaming/' | relative_url }}) for the prerelease disclaimer and configuration steps.
